# Build Doc — Sight Words Lucito

## Local dev
1. Clone repo. Open index.html in any browser. No server needed.
2. Edit curriculum words in the WORDS array at top of index.html.
3. Test voice: Chrome/Silk support en-US voices; pick a female voice if available.

## Deploy (free)
1. GitHub Settings > Pages > Branch: main, folder: root. Save.
2. Wait 1-2 minutes. Site live at https://joebonilla53.github.io/sight-words-lucito/
3. Custom domain optional later via leadthewaylogistics.info subdomain if desired.

## Fire tablet install
1. Open Silk browser, go to the URL.
2. Tap menu (three lines) > Add to Home screen. Name it "Lucito Words."
3. Icon appears on home screen. Opens fullscreen-ish in browser.
4. Progress persists in the tablet's browser storage — don't clear browser data.
